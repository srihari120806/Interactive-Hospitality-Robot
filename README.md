# 🤖 Interactive Hospitality Robot

An Arduino and ESP32-based interactive hospitality robot designed to welcome and engage guests. It features Bluetooth-controlled mobility using an ESP32-based RC car system, personalized welcome messages displayed on an LCD screen, and motor-controlled hands designed to present a rose or bouquet to guests.

## Features
- 🚗 Bluetooth-controlled mobile base using ESP32
- 🖥️ LCD welcome message display
- 🌹 Motor-controlled hands for rose/bouquet presentation
- 🤖 Interactive hospitality-focused robotic design
- 🔧 Arduino-based control and embedded hardware integration

## Technologies
- Arduino
- ESP32
- Bluetooth
- Robotics
- Embedded Systems
- LCD Display
- Motors

## System Overview
The robot combines a mobile ESP32 Bluetooth RC-car-style base with an interactive upper section. The LCD provides the welcome message while motor-controlled hands perform the rose/bouquet presentation.
